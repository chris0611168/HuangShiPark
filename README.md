## 五、操作投影片

- 用**瀏覽器**開啟 `黃石公園之行說法_投影片.html`（雙擊即可，預設會用瀏覽器開）。
- 翻頁：按 →／空白鍵，或點左右箭頭、底部圓點。
- **編輯方式**：用文字編輯器（記事本／VS Code）開啟 html 改內容後存檔，再回到瀏覽器按 **F5 重新整理**。
  - 不要用雙擊在瀏覽器裡改，那是唯讀。
